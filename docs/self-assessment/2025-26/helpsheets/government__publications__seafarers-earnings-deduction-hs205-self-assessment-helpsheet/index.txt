Find out if you qualify for the Seafarers' Earnings Deduction.

This guide helps you decide if you qualify for the Seafarers’ Earnings Deduction. If you do, it allows you to work out the eligible period and the deduction you need to make. It covers work on ships (https://www.gov.uk/guidance/seafarers-earnings-deduction-tax-relief-if-you-work-on-a-ship), but not other offshore installations.
