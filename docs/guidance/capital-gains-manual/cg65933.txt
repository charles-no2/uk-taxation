Losses: loans to traders: loan used partly for trade purposes
Identifier: CG65933
Source: https://www.gov.uk/hmrc-internal-manuals/capital-gains-manual/cg65933
Published: 2016-03-12T12:03:14+00:00
Updated: 2016-01-26T16:36:35+00:00
Retrieved (UTC): 2026-09-18T14:45:52.161649+00:00

If a loan has been used partly for trade purposes and partly for non-trade purposes, for example to build premises partly for trade and partly for private use, relief may be given for the trade use proportion. If a loan has been used for mixed purposes, no relief is available. It should be noted that a loan used to repay a loan which was used for trade purposes should itself be treated as if it has been used for trade purposes, see CG65995 concerning novation of debts.
