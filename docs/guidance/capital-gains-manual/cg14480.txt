Consideration for disposal: introduction

This section sets out the rules which determine what figure should be used as consideration for disposal of an asset. In most transactions this will be the value that was actually received. However there are special rules governing certain circumstances and these need to be considered. The topics covered are:

- meaning of consideration, see CG14500+

- market value rule, see CG14530+

- connected persons, see CG14560+

- assets disposed of in a series of transactions between connected persons, see CG14650+

- apportionment of consideration and composite transactions, see CG14771+

- contingent liabilities, see CG14800+

Deferred consideration is covered in detail in CG14850+.
