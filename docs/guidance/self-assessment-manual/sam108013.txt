Where you want to amend a permanent note follow steps 1 - 3 below

-

Use function MAINTAIN PERMANENT NOTES to view the permanent notes already recorded

-

Select the line number of the permanent note you want to amend, then

* Select the [Amend Note] button

- On the Amend Permanent Note screen

* Amend the text of the permanent note * Select the [OK] button
