OK

Once you are satisfied that the calculation is correct, choose the OK button to move on to the next Assessment Group (IHTM31012 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31012)).

You cannot return to that calculation again to make any further adjustments once you have clicked OK.

Cancel

Use the Cancel button to stop raising the calculation at any time. If you do this, COMPASS will cancel all calculations and return you to the window you started from.
