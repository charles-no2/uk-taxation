Premium Bonds (box 54): investigating values
Identifier: IHTM10081
Source: https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm10081
Published: 2016-03-20T09:27:25+00:00
Updated: 2016-02-11T16:57:35+00:00
Retrieved (UTC): 2026-09-18T14:55:00.745944+00:00

The total value of all Premium Bonds owned by the deceased should be included in box 54 and at box 3 on form IHT406 This should also include any unclaimed or uncashed prizes (IHTM10082 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm10082)).

In practice, you should normally accept the value given. You should only raise enquiries if you have information from elsewhere to suggest that the value of the bonds has been understated or prizes have not been included.
