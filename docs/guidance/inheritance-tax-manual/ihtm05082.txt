Form Cap A5C (England, Wales and Northern Ireland): procedure on receipt of Form Cap A5C
Identifier: IHTM05082

Published: 2016-03-20T09:21:10+00:00
Updated: 2019-06-10T09:34:49+01:00

Where a form Cap A5C is completed (IHTM05023 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm05023)), and is delivered to us after the grant, we will deal with it in the following way:

- where we have an existing file, the A5C will be attached to the file and referred for review (IHTM05083 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm05083))

- if there is no existing file the A5C will be sent directly to the file creation staff, who will create a new file and refer the A5C for review

If an A5C relating to an application for a de bonis non grant (IHTM05102 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm05102)) or for a grant of double probate (IHTM05103 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm05103)) is received before the grant is issued, the form should be returned immediately to the sender, who should be asked to send the application to the Probate Registry.
