Reduced rate for gifts to charity: abatement: caused by grossing up
Identifier: IHTM45034
Source: https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm45034
Published: 2016-04-09T10:33:01+01:00
Updated: 2016-02-11T17:27:59+00:00
Retrieved (UTC): 2026-09-18T15:10:45.709558+00:00

The value of the chargeable transfer cannot be more than the value of the estate for Inheritance Tax purposes, so where the grossed value of the estate exceeds that value, IHTA84/S37(2) applies, with the result that the grossed up value is reduced to the value of the estate as described at IHTM12088 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm12088). You should use this value of the estate to calculate the baseline and apply the 10% test.
