The following is a list of keyboard shortcuts for various actions within the COMPASS program.

To select File from a menu: ALT + F

To select a button: ALT + underlined letter

To select Register from drop down menu: R

To open a list: Alt + down arrow

To select an item in a list: Spacebar

To cancel a selection in a list: Enter

To move from option to option – forwards: Tab

To move from option to option – backwards: Shift + Tab

To move the selection cursor from option to option: An arrow key

To move the selection cursor left, right, up or down: An arrow key

To identify a specific place of Grant within the probate screen: S + down arrow

To move to ‘Next Screen’ button: Tab

To move to ‘Cancel’ button: Tab

To move to next screen: Enter or Alt + N

To move to previous screen: Alt + P

To remove a warning: Enter
