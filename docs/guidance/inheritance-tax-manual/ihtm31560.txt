To apply money on deposit enter your deposit details separately at the end of the calculation.

On COMPASS, select the money button (IHTM31190 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31190)) and enter all the details of the deposit. Make sure you write the deposit number accurately so it is correctly identified, and the EDP (IHTM31211 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31211)) so that the interest is charged correctly.

If you raise a calculation on the manual calculation template (IHTM31301), use the ‘Money applied from deposit’ section.

Applying a deposit will affect the interest charge (IHTM31513 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31513)).
