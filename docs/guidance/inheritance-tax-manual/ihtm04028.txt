Structure of the charge: what is the value transferred?
Identifier: IHTM04028
Source: https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm04028
Published: 2016-03-20T09:15:17+00:00
Updated: 2018-03-27T15:32:50+01:00
Retrieved (UTC): 2026-09-18T14:52:21.782300+00:00

The value transferred by a chargeable transfer is calculated in a different way depending on the occasion of charge to Inheritance Tax

- for lifetime transfers, the value transferred is the amount of the loss to the transferor’s estate, (IHTM04054 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm04054))

- on death, the value transferred is equal to the value of the deceased’s estate, immediately before death, (IHTM04044 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm04044))

- for a lifetime transfer of settled property in which a qualifying interest in possession subsists, the value transferred is equal to the value of the property in which the interest subsisted, (IHTM04093 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm04093))

- for relevant property trusts, the value transferred depends upon the actual occasion of charge. (IHTM04097 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm04097))
