The basic background window includes a number of drop-down menus and icons at the top of the screen.

The menus are:

- File (IHTM31114 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31114))

- Amend (IHTM31115 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31115))

- Calculation (IHTM31116 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31116))

- Options (IHTM31117 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31117))

- Window (IHTM31118 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31118))

- Help (IHTM31118 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31118))

Most of the options in the menus will only work once you have selected a case record from the case index (IHTM31112 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31112)).

As you continue through the COMPASS program pages, different windows will open, each with a description of itself on the title bar. The windows open on top of each other, which uses up a lot of computer memory. Try to limit the amount of windows open at any time. Working from the case outline window will help with this.
