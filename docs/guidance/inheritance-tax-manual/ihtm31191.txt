You can access the notes box through the button at the bottom of the assessment window. You can type a short note of no more than 192 characters (including spaces) in the box.

- Press enter when you come to the end of each line of text.

- Use the backspace key if you make any mistakes.

- What you type here is how the text will appear on the printed calculation.

- This box should only be used where the taxpayer or agent is expecting the calculation and that calculation is straightforward.

If you need to add a more substantial note, you should send a covering letter.

Choose ‘OK’ to return to the assessment window.
