Once you have raised (IHTM31181 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm31181)) all your calculations on the death estate or lifetime transfer, the Issue/Withdraw assessments window will appear. This shows a table of the calculations raised during that session - their status is shown as ‘raised’.

If you want to keep a calculation, highlight it and select the Issue button.

Withdraw any unwanted calculations by selecting the Withdraw button - COMPASS will not save the calculation or print it.

Already issued calculations

If there is an earlier issued calculation for an assessment group which has not been paid, COMPASS will inform you that the previous calculation will be withdrawn automatically if the calculation you are raising now is issued. Choose OK to confirm that the earlier assessment should be withdrawn.

If you wish to cancel all the calculations you raised in the session, select the Cancel button at the foot of the screen.

Otherwise select ‘OK’.

Printing

COMPASS will ask you whether you want to print the calculations you have just issued. Choose ‘OK’ to confirm. Indicate the number of prints you need.

COMPASS will then ask you whether you want to save the calculations you have just issued. Choose OK to confirm.

Manual calculations

You must keep copies on your file (IHTM31305).

The same applies for grossing and interaction calculations.

Non-death cases (settlements)

You must keep paper copies in your file of:

- the rate chargeable (IHT305A or IHT306A) and

- the calculation going to the taxpayer.

This applies to both COMPASS and manual calculations.

IHT payslips

All COMPASS calculations are sent with a pre-printed payslip. Very rarely you may need to send a customer a manual payslip. If you do this make sure that you write the file reference number on the payslip before you send it.
