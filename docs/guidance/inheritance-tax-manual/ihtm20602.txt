Life Policies: Countrywide (formerly Premium Life) Assurance Company policies: what action to take
Identifier: IHTM20602
Source: https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm20602
Published: 2016-04-09T09:34:22+01:00
Updated: 2016-02-11T17:08:21+00:00
Retrieved (UTC): 2026-09-18T15:00:27.452498+00:00

If you come across a policy issued by Countrywide, you should first consult IHTM20603 (https://www.gov.uk/hmrc-internal-manuals/inheritance-tax-manual/ihtm20603) to work out which scheme you are dealing with. Then:

- If you think you are dealing with the Asset Protection Plan you should refer the file to the Actuarial Team immediately.

- If you think you are dealing with the CTT or IHT Mitigation Plan you should refer the file to Litigation immediately.

- If you are satisfied that you are dealing with neither scheme you should deal with the matter in accordance with any other specific instructions in this section of guidance.

- If you are unsure you should consult the Actuarial Team for advice immediately.
