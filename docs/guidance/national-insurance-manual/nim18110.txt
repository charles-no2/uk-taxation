Class 1B NICs: liability: what if Class 1 or Class 1A liability arises before the PSA is formally agreed?
Identifier: NIM18110
Source: https://www.gov.uk/hmrc-internal-manuals/national-insurance-manual/nim18110
Published: 2016-04-11T17:36:42+01:00
Updated: 2022-04-20T12:01:16+01:00
Retrieved (UTC): 2026-09-18T15:12:06.929857+00:00

The payment of Class 1B NICs replaces the payment of primary and secondary Class 1 NICs and the payment of Class 1A NICs. But a liability for Class 1B NICs can only replace a liability for Class 1 or Class 1A NICs which has not yet become due for payment.

This means that if a PSA is agreed before the due date for the payment of the Class 1 or Class 1A NICs then the Class 1 or Class 1A liability is replaced by a liability for Class 1B NICs. The due date for payment of Class 1 NICs is the 19 of the month and for Class 1A NICs it is the 19 July following the end of the tax year. If the PSA is agreed later than these dates, the original Class 1 or Class 1A liability will stand.

The following examples illustrate this principle more clearly.

Example 1

- PSA for 2025 to 2026 tax year

- Agreement entered into on 27 August 2025

- PSA includes items which would normally give rise to a Class 1 liability.

Class 1 NICs should have been paid on 19th of each month.

Class 1 should therefore already have been paid to 19 August 2025 when the PSA was agreed.

Class 1B NICs are payable only from 20 August 2025 - that is, from the date from which the Class 1 NICs have not yet become payable.

Class 1 NICs will cease to be payable from 20 August 2025.

Example 2

- PSA for 2025 to 2026 year.

- Agreement entered into on 7 April 2025.

- PSA revised 27 August 2025 to include additional items which would normally give rise to a Class 1 NICs liability.

Class 1 NICs should have been paid on 19th of every month.

Class 1 should therefore already have been paid to 19 August 2025 on the items not covered by the PSA prior to 27 August 2025.

Class 1B NICs are payable only from 20 August 2025 in relation to the additional items which would otherwise give rise to a Class 1 NICs liability and which are included in the PSA from 27 August 2025.

Class 1B NICs are payable for the whole year on any items which would normally have given rise to a liability for Class 1 NICs and which were included in the PSA on 7 April 2025.

Example 3

- PSA for 2025 to 2026 tax year.

- Agreement entered into in June 2025.

- PSA includes a number of benefits which would normally give rise to a Class 1A NICs liability for the whole tax year.

As Class 1A NICs are not due for payment until 19 July 2026 Class 1B NICs will be payable for the whole year instead of Class 1A.
