Section 10(4) of the Social Security Contributions and Benefits Act 1992 (SSCBA 1992)

NIM15020 (https://www.gov.uk/hmrc-internal-manuals/national-insurance-manual/nim15020) explains how to work out which percentage rate should be used to calculate Class 1A NICs. The table below shows the Class 1 NICs secondary percentage rates which are used to calculate Class 1A NICs.
