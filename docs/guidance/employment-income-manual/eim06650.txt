Employment income: exemption for suggestion  scheme awards: two or more awards for same suggestion on different occasions
Identifier: EIM06650
Source: https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim06650
Published: 2014-05-22T10:00:00+01:00
Updated: 2015-10-02T11:31:27+01:00
Retrieved (UTC): 2026-09-18T14:19:32.383608+00:00

Section 322(3) ITEPA 2003

EIM06640 explained how the exempt amount (the “suggestion maximum”) for a financial benefit award is apportioned when an employer makes two or more awards for the same suggestion on the same occasion. There are further rules for deciding how much is exempt from tax when two or more awards are made, for the same suggestion, at different times. This could happen if an employer made an initial award for a promising suggestion followed by a later award when the suggestion has been fully evaluated.

- The basic rule is that the total amount qualifying for exemption in respect of a single suggestion must not exceed the suggestion maximum calculated in accordance with EIM06630 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim06630).

- The suggestion maximum is set against the earliest award(s) first, applying the rule in EIM06640 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim06640) if awards were made to two or more people at the same time.

- If the suggestion maximum is not completely used up against the first award, the balance can be set against any later award, and so on (see example EIM06651 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim06651)).

- If a later award is made to two or more people at the same time, the balance of the suggestion maximum is apportioned between them as described in EIM06640 (see example EIM06652 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim06652)).
