Section 266 ITEPA 2003

No liability to income tax arises under Part 3 Chapter 4 ITEPA 2003 for non-cash vouchers used to:

- travel on a work’s bus for a qualifying journey, see EIM21850 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21850) for the conditions that need to be met

- travel on a public bus for a qualifying journey, see EIM21855 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21855) for the conditions that need to be met

- provide a cycle or safety equipment for a cycle, see EIM21664 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21664) for the conditions that need to be met

- provide sporting and recreational facilities, see EIM21825 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21825) for the conditions that need to be met

- attend an annual party or similar function provided by an employer for its employees, see EIM21690 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21690) for the conditions that need to be met

- provide a member of the Armed Forces with leave travel facilities, see EIM21733 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21733) for more information

- obtain meals at a workplace canteen, see EIM21670 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21670) for more information

- obtain an influenza (flu) vaccination, see EIM21874 (https://www.gov.uk/hmrc-internal-manuals/employment-income-manual/eim21874) for more information
